# Calculator – CodeAlpha Internship

## About the Project

This Calculator is a web-based application developed as part of my Frontend Development Internship at CodeAlpha.

It provides a simple and interactive interface for performing basic mathematical calculations.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear button
- Interactive calculator buttons
- Responsive user interface

## Project Structure

- `index.html` – Calculator structure
- `style.css` – Styling and layout
- `script.js` – Calculator functionality
